# 🧠 Quiz App

A simple interactive quiz application built using **HTML, CSS, and JavaScript**.  
This project demonstrates DOM manipulation, event handling, and basic state management in JavaScript.

---

## 🚀 Features

- Multiple-choice questions
- Dynamic question rendering
- Score tracking system
- Answer validation (correct/wrong feedback)
- Progress indicator (Question 1/4 style)
- Restart quiz option
- Clean and responsive UI

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)

---


---

## ⚙️ How It Works

1. Questions are stored in a JavaScript array of objects.
2. Each question contains:
   - question text
   - multiple options
   - correct answer index
3. JavaScript dynamically loads each question into the DOM.
4. User selects an option and receives instant feedback.
5. Score is calculated and displayed at the end.
